4. 不改写第一阶段历史日志、测试事实或人工贡献；不将新计划补写成旧阶段已完成的工作。

### B 题目内容和版本

1. 区分题目身份、正式题目版本、题目在某份问卷中的实例；题目版本与问卷发布版本分别管理。
2. 只有用户显式保存为正式题目版本时才生成新版本，普通编辑草稿不生成版本。正式版本内容不可覆盖。
3. 恢复旧版时根据旧版生成一个新版本，记录恢复来源并保留完整历史，不删除中间版本。
4. 版本可以基于任意已有正式版本创建，须保存准确的来源关系；版本号大小不能替代真实父子来源。
5. 复用和版本化的内容包括题干、题型、选项、输入限制。
6. 必答、题序和跳转属于具体问卷配置，不绑定进可复用的正式题目内容；但仍随问卷发布快照固定，以解释历史答卷。

### C 问卷采用题目版本

1. 问卷始终固定引用明确的题目版本，不自动跟随最新版本。
2. 有权访问的新版出现时提示更新，由问卷创建者选择，也可以继续使用旧版。
3. 草稿可以替换版本；正在收集的问卷须先暂停，替换并检查后重新发布，随后收集的回答使用新定义。
4. 重新发布沿用原问卷ID和分享链接，历史发布快照、旧答卷及其版本归属保留；关闭后不重开，沿用第一阶段规则。
5. 替换时尽量保留稳定问卷内实例ID、位置和必答配置，重新校验跳转；选项删除或题型变化导致规则失效时明确提示，阻止无效定义发布，不静默删除或猜测替代规则。
6. 采用已存在的题目版本会产生新的问卷发布版本，不应无理由再复制生成新的正式题目版本。

### D 指定用户共享和派生

1. 默认私有；按用户名向指定的已注册用户共享，不是面向所有人的公开题目库。
2. 题目级共享覆盖该题全部正式版本和后续正式新版，不共享作者的编辑草稿。
3. 接收者可以引用正式版本，不能修改共享者的原题。
4. 接收者修改复用内容时，派生为属于自己的新题目，保留来源并独立维护身份和版本历史；修改必答、题序和跳转不需派生。
5. 派生题与原题默认不合并统计。
6. 取消共享后，已正式保存到问卷的引用继续保留，包括草稿，仍可正常发布和填写；已发布问卷、历史答卷和撤销前已生成的派生题保留。
7. 取消共享后，不允许向其他问卷新增引用、获取后续新版或创建新的派生题。设计清楚已保存实例的保留使用权与新增使用权的区别，不能把存量引用当成任意新增引用的授权。

### E 使用情况

1. 查询某个题目及版本被哪些问卷使用，区分草稿使用、当前发布使用和仅历史使用，避免将多个发布快照误计成多份问卷。
2. 本人的问卷可以展示标题和进入入口。
3. 他人的问卷展示使用者用户名、稳定问卷编号、引用版本和使用状态。
4. 引用记录本身不授予查看他人问卷内容、答卷、统计或管理问卷的权限；接口必须按该边界返回字段。
5. 派生关系单列，不算作对原题版本的直接引用。

### F 题库

1. 每人可管理多个题库，同一题目可加入多个题库，保留同一身份和版本历史，不因加入题库复制题目。
2. 可以创建、重命名、删除题库、加入和移出题目；移出或删除题库只改变整理关系，题目、共享和已有问卷引用保留。
3. 选题进入问卷时明确版本，题库可查看最新正式版本和历史版本。
4. 本阶段共享以题目为单位，不增加整库共享。

### G 公开问卷模板广场 作为扩展需求单独编号

1. 广场展示可复用的问卷模板，不是答卷/统计公开平台，也不是单纯的填写招募入口。
2. 发布者自愿公开；模板包含问卷结构和题目配置，不包含答卷、填写者身份及统计数据。
3. 从明确的已发布问卷版本生成确定的模板内容，模板上下架与源问卷是否正在收集分别管理。
4. 使用模板生成使用者自己的新问卷草稿，保留来源；使用者后续修改不影响原模板或其他用户的问卷。
5. 未修改复用内容的题目保留原题身份及模板固定的版本；修改复用内容时派生为自己的题目。新问卷的实例、规则标识和跳转目标必须正确重建映射，不能串到源问卷。
6. 模板使用权仅覆盖模板包含的题目版本，不开放原题其他历史/未来版本；需要持续访问整道题时仍通过指定用户共享。
7. 定向共享不自动包含公开分发权；模板包含他人题目时必须有作者明确的公开分发授权。服务端核查，不信任客户端勾选声明或复制来源字段。
8. 模板更新不自动改变已创建问卷；下架停止后续选用，已生成问卷保留。
9. 公开分发授权的具体粒度、撤销对既有公开模板后续分发的影响等若此前未决定，要提出明确推荐及影响，标为暂定，不冒充已确认规则；不因此跳过其余设计交付。

### H 跨问卷统计

1. 沿用现有问卷权限，只汇总本人创建的问卷，不新增向他人授予问卷统计权限的模块。
2. 统计范围为同一题目身份、同一正式题目版本；派生题独立，默认不跨版本合并。
3. 来源由答卷实际提交时对应的问卷发布快照确定，不能按当前草稿或最新题目内容重解释旧回答。
4. 题目共享者或模板作者不能自动读取其他用户的答卷或统计。
5. 保留第一阶段按问卷及发布版本的统计，新增跨问卷统计入口，二者共存。
6. 沿用第一阶段有效回答份数/选择次数口径，明确不等于去重人数；真实重复提交可以计入，幂等重放不能多算。
7. 设计各题型的结果、分母、空值、被跳过题、无数据、分页和数字分布展示方式。教师提到年龄总体分布，不要仅返回均值就宣称全部覆盖；额外统计细节说明为推荐设计。
