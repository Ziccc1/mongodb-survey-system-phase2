## 2 已确认规则登记

以下来自用户转交的Prompt，不再作为待确认问题；字母与Prompt第三节一致。

| 决策 | 已确认内容与边界 |
| --- | --- |
| P2-D-A | 沿用users、surveys、survey_versions、responses、原栈和工程；账号/owner/四题型/校验/向后跳/状态/登录匿名/整卷防重/提交幂等/历史/分版本统计继续存在；不重写旧日志、测试或人工贡献 |
| P2-D-B | 身份、正式题版本、问卷实例不同；普通草稿不建版，只有显式正式保存建版且不可覆盖；可从任意正式版创建新版本；恢复另建版，记来源且不删中间历史；题干、题型、选项、输入限制可复用，必答/题序/跳转属于实例并进入发布快照 |
| P2-D-C | 固定具体题版本，不追最新；有权访问新版才提示，创建者选择；草稿可换，收集中先暂停、检查、重发，同ID/链接、保留旧快照/答卷；closed不重开；保留实例ID/位置/必答，规则失效明确提示并阻发布；采用现存题版只新建问卷发布版 |
| P2-D-D | 默认私有，按用户名共享给已注册用户；题目级覆盖全部正式历史及未来版，排除编辑草稿；他人只能引用，改内容须派生自己身份及来源，改实例配置不派生；派生统计独立；撤销保留已正式存入问卷的引用（含草稿）、已发布/历史/既有派生，禁止其他问卷新引、获取新版和新派生；存量实例权不可当通行授权 |
| P2-D-E | 按问卷汇总草稿、当前、仅历史使用；本人可标题/入口，他人仅使用者用户名、稳定问卷编号、版本、状态；引用不赋予问卷正文、管理、答卷和统计权限；派生另列 |
| P2-D-F | 多题库，同题多库仍一身份/历史；创建、改名、删除、加/移成员；移出或删库保题、共享与引用；选题明确版本、可查最新及历史；不做整库共享 |
| P2-D-G | 自愿发布可复用结构模板，不公开答卷、身份、统计；源明确问卷发布版，模板上下架独立于收集状态；使用生自己新草稿、来源固定，后改互不影响；未改内容沿原身份/固定版，改内容派生；实例/规则/目标重新映射；权仅模板含版本；他人题需作者明确公开分发权，服务端核实；更新不追踪，停售保已生成问卷 |
| P2-D-G1 | **P2-004用户新增确认**：派生仅取得独立编辑、版本管理及自用权，不自动取得来源公开分发权；原样、修改、另存正式版、恢复、再次派生均保留来源限制。多级来源不能由中间作者代授或转授；派生统计仍独立 |
| P2-D-H | 只汇总自己创建问卷，同题同正式版，派生及其他版排除；答案来源由提交快照决定；共享者/模板作者不因此获答卷权限；原分问卷分发布版统计与新增入口并存；真实主动重复计份数，幂等重放不多算，不能说去重人数；各题型含空值/跳过/无数据/分页/数字分布 |

## P2-004 技术细化与追踪

用户确认的是P2-D-G1的来源限制继承；**逐层固定源正式版本、distributionSource、distributionProof、链路摘要、门闩范围和Usage计算顺序是AI技术推荐**，不冒充用户指定字段。S04/S05/S06已确认；下文按已确认授权粒度实施。

公开检查从实际所用正式题版沿不可变distributionSource追溯到可证原创根；每层作者只控制该层的权利。对实际模板publisher以外作者的每个具体版本，都要有给该publisher的当前有效公开授权；自己持有某层只免该层授权。A/Qv1→B/Fv1→C/Hv1，C须A对Qv1及B对Fv1分别向C授权；A给B的权不能转给C。共享/模板实例窄权仅支持自用及派生。无来源记录不等于他人派生，也不等于已证原创：保持自用，公开等待证据核验；缺失、伪造、循环不放行。见[来源与模板主契约](../database-design.md#7-公开模板与分发授权)、L08/A01—A03/M01—M06及T37—T45。

P2-D-E细化：每个versions项为{versionId,version,isDraft,isCurrent,hasHistorical}，历史必须是非当前发布快照；同版可三者皆true。先versionId过滤，再按surveyId+题版去重及问卷汇总，问卷isDraft/isCurrent取OR，onlyHistorical=无草稿且无当前且有历史。派生另列、他人字段白名单不变。见U01及T46—T50。
