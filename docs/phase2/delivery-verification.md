## 可用于报告的增量事实

课程原要求强调：第一阶段保留核心结构；第二阶段在原代码上扩展；必须解释原设计、新问题、修改原因、结构变化、程序调整、兼容问题及旧功能保障。原要求见 `大作业一.docx`，八项需求变更见 `大作业一：需求变更.docx`。它们是需求来源，当前用户的“不代写Word”决定优先。

| 原设计或问题 | 第二阶段的实际调整 | 兼容与验证 |
| --- | --- | --- |
| 题内容嵌在问卷，难以复用 | 在原4集合外扩展题身份、不可变正式题版、题库、共享、引用绑定、模板与回执等9集合 | 原users/surveys/survey_versions/responses继续存在，合计13集合 |
| 题内容与问卷设置混在一起 | Content含题干/题型/选项/校验；Config含必答/顺序/跳转，实例独立 | 只改必答/跳转不新建题版；C卷独立配置实测 |
| 修改复用题可能影响历史 | 显式正式保存才新建题版；问卷固定具体版本；暂停后主动替换并重发 | 旧发布快照和答案保留；原同链接重发语义保留 |
| 需要追溯与恢复 | 记录父版本、恢复来源和派生来源；恢复新增正式版，不覆盖待保存草稿 | AT02恢复v3、基于v2的草稿保留；真实迁移无猜测父子关系 |
| 指定用户共享和隐私 | 共享用于新选用，撤权后禁止新引用/一般派生/升级，保留已取得实例；使用情况只显示允许字段 | 主流程、权限矩阵、撤权存量保存/统计及越权拒绝均实测 |
| 单卷统计不能支持复用题 | 按本人有权问卷＋同题身份＋同正式版汇总 | 跳过/未答不补零；不同题版、派生题和他人卷分开 |
| 模板广场公开范围 | 公开固定结构，不公开源答卷/统计；上游具体题版对具体发布者逐项授权，不可转授 | 原模板固定性、撤权/恢复、D派生后公开被拒均实测 |
| 旧数据没有二期来源映射 | 真实旧数据从冷备份恢复，按稳定实例保守映射；原快照/答卷/BSON/hash不改 | 两个真实目标各6卷升级，新增16正式题版、35绑定；重复apply均0提交/6跳过 |
| 数据库角色只是模板 | 认证模式部署到当前二期实例，受限应用账号实际执行API | 历史集合禁止update/delete、DDL及越库拒绝；当前API ready和真实登录/建卷/发布正常 |

数据库角色不能限制同一集合中的特定字段或 `scope` 行，因此题目草稿、模板内容和publication绑定的更细不变性仍由应用事务、来源校验与接口保证；不要在报告中写成“任何数据库账号都无法修改任何历史”。本机单节点、副本集事务和回环部署不等于公网生产或多节点高可用。
