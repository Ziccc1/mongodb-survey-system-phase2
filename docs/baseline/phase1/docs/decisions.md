# 需求澄清与设计约定

创建日期：2026-10-15。

本文件记录项目组正式业务决定。2026-10-15 初始 D01—D12 已确认；随后用户明确调整问卷修改规则，修订 D06 并新增 D13—D18，当前以本次正式决定为准。旧 D06 的已确认历史保留在下方替换记录，不能继续作为当前限制。这些是项目组决定，不代表教师发布了新的作业条款。填写草稿/自动保存/恢复仍可选，问卷定义的编辑保存是必需功能。

状态可使用：待确认、采用暂定方案、已确认、已替换。采用暂定方案时记录决定人和日期；获得教师答复时记录原话或依据。

## D06 替换记录

旧 D06（先前已确认，现已替换）：草稿可改；发布须暂停，尚无答卷可改结构；已有答卷则锁定结构，修改通过复制新问卷完成。

替换原因：用户本轮要求暂停后可在原问卷继续修改并保留历史，以不可变发布快照保障旧答卷解释。因而“首次提交后永久锁定”和“submissionCount=0 才能编辑”同时退出当前业务规则；旧字段 structureLocked 保留，不再据其阻止编辑。旧平台调研、旧 AI 日志和旧测试仍是历史资料，不回写。

八项用户正式行为已经确认；survey_versions 字段划分、每次显式重发生成新号、发布 key 幂等、迁移细节是 AI 提出的落实方案，见 [版本变更计划](versioning-change-plan.md)，不冒充用户逐项设计。

## 第二阶段预留

阶段一完成后保留其设计与代码基线。新增需求先填写影响分析，再修改实现；记录旧数据如何兼容或迁移、哪些测试证明旧功能仍可用。避免为了未知的新需求提前实现复杂功能。
