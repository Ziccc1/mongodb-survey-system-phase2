## 约定

- 网页入口 `http://localhost:5200`。账号和通用建卷动作见准备分册；当前是否在线以实际访问为准。
- R01、AT01、AT02是复用题代号；Q1等仅是某份卷内题序，系统ID另记。
- “R01/v2”指题目正式版，“W02发布v2”指问卷发布版，两套编号独立。
- 只在配方明确要求“选用”时复用原题；其余题本地新建并逐题正式化。照抄题干不是复用。
- 答卷表外的成功提交会改变预期；非法输入先用预览。失败时保留现场，不删除数据凑结果。
- 本轮只改文档，不代为注册、创建问卷或填答卷，不重跑业务自动化。真实P1迁移、认证角色部署另行验收。
