**实际执行更新（2026-10-24—25）：** 本册后续主流程已完成，见[执行记录与差异](../phase2-runs/assisted-manual-20261024/README.md)。下面是原测试配方；开始辅助执行时T01和源卷答卷已由用户建立，源卷实际允许匿名/禁止重复，沿用而未修改。另有B自己的甲/乙卷已经引用AT02/v1，所以“B仅7”只适用于指定W04范围，不能套用到全部本人问卷。
