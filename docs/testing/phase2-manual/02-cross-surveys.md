## 第二轮：A新正式版，B只换W02

1. A打开R01，选择正式v1，“以此版编辑草稿”；题干改为“P2-MAN-20261024-02 本次活动满意度（调整题干）”，类型与0—100整数限制不变。
2. 仅保存编辑草稿时，正式历史仍只有v1，B不得读到该草稿；再点一次“保存正式版本”产生**题目v2**。
3. B刷新W02/W03，应提示可用新版，但两卷仍固定v1，题干未自动换。先截图。
4. B暂停**W02**，从来源“选择版本替换”明确选R01/v2，确认并保存；原Q1实例应仍保留，必答仍是“是”。重新发布成**W02发布v2**，填写链接不变。
5. W03始终不暂停、不替换、不重发，继续固定R01/v1。
6. A通过W02填写链接提交一份：Q1=90，Q2=“换版后填写”，选择匿名。只成功提交一次，编号W02-R2。

## 恢复旧版：新v3和未正式保存的草稿

1. A选择R01/v2作为编辑基线，改题干为“P2-MAN-20261024-02 待保存草稿”，只“保存编辑草稿”，不要正式保存。
2. 选择正式历史v1，点“恢复此版为新正式版本”。应新增**题目v3**，内容与v1一致、恢复来源为v1，v1/v2均保留。
3. 页面中的“待保存草稿”仍在，不能被恢复覆盖。刷新再核对。不要再点正式保存，否则会产生额外v4。
4. B的W02仍用v2，W03仍用v1；历史答卷和上述统计不变。v3只是同题的新正式版，不与v1合并统计。
5. A在“使用情况”按版本查看：W02的v1属于历史发布引用、v2属于当前引用；W03的v1属于当前引用。他人行可展示B用户名和独立问卷编号，应不含可进入管理的链接、答卷、源问卷标题。对照[记录表](06-results.md)里的编号识别甲/乙。
